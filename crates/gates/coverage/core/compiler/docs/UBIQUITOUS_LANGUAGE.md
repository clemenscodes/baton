# The ubiquitous language

| Word | What it means |
|---|---|
| Compiler | The compiler of Rust, rustc, which names the directory of its library, beside which the profile tools lie. |
| Compose Library Invocation | To compose the invocation that asks the compiler for the directory of its library. |
| Gates Coverage Core Compiler | The crate gates_coverage_core_compiler, the crate of the domain of the coverage that holds the compiler, which composes the invocation that names its library. |
| Library | The library of the compiler for its host, whose directory the compiler names on request. |
| Library Query | The arguments --print target-libdir, with which the compiler names the directory of its library. |
| Program Name | The name rustc of the compiler. |
