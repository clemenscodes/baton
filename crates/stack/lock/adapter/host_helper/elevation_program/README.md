# stack_lock_adapter_host_helper_elevation_program

The adapter of the port HostHelper of stack_lock_application, which runs baton_host through an elevation program such as sudo. Its tests run with
`cargo nextest run --profile debug -p stack_lock_adapter_host_helper_elevation_program`.
