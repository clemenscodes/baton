# stack_lock_adapter_lock_record_file_system

The adapter of the port LockRecord of stack_lock_application over a file of JSON for every lock and a lease of flock. Its tests run with
`cargo nextest run --profile debug -p stack_lock_adapter_lock_record_file_system`.
