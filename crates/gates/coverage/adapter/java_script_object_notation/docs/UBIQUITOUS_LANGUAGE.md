# The ubiquitous language

| Word | What it means |
|---|---|
| Absence | The lack of what a measurement needs, named by what is lacking. |
| Annotation | The kind of an export region of every export kind above 0, such as an expansion, a skipped range, the space between code or a branch, which the adapter Java Script Object Notation passes over. |
| Artifact Profile | The profile of Cargo that a message names for its artifact, which states whether the artifact is a test. |
| Artifact Reason | The reason compiler-artifact of a message that names what the build made. |
| Code | The kind of an export region of the export kind 0, which counts the runs of a piece of code, the one kind the adapter Java Script Object Notation decodes and the default kind. |
| Coverage | The crate that judges whether the tests of a crate reach every region of its sources outside their test modules, and the context of that crate. |
| Criterion | A closure that decides whether a value is the one a function looks for, named for that value, such as the criterion of the separator word or of the text of a message. |
| Data | The files and the functions of one binary of an export, whose regions count only in the files it keeps. |
| Decode Region | To decode a region out of an export region and the filenames of its function, and the regions of the kind code out of the export regions of a function, out of a function, out of the functions of a data, out of a data or out of an export. |
| Decode Test Executables | To decode the test executables from every message of Cargo on the output of a build. |
| End Column | The column an export region ends at, as llvm-cov writes it. |
| End Line | The line an export region ends on, as llvm-cov writes it. |
| Export | The text that llvm-cov export writes in the Java Script Object Notation, holding the data of every binary of the tests, which a measurement writes into its report file, and the error of the adapter Java Script Object Notation for a text that is no export, which carries the error of serde_json. |
| Export Kind | The kind of an export region as an export of llvm-cov writes it, 0 for a region of code. |
| Export Region | A region as an export of llvm-cov writes it, a list of its start line, its start column, its end line, its end column, its execution count, its file index, the index of its expansion, which the adapter Java Script Object Notation does not read, and its export kind, which decodes into a region of the filename its file index locates among the filenames of its function. |
| Export Regions | The export regions of a function, of which only those of the kind code are decoded, each into a region of the filename its file index locates. |
| File | A file of an export, named by its filename, whose regions the data keeps, and the error of a code region whose file index its function lacks, which names that file index and the file count of that function; and the file of syn, the items of a source as syn parses them, whose modules the test module visitor visits. |
| File Count | How many filenames a function of an export holds, below which a file index has to lie. |
| File Index | The index of the file of an export region among the filenames of its function. |
| Filename | The path of a file an export keeps, as llvm-cov names the field. |
| Filenames | The paths of the files a function of an export was made from, as llvm-cov names the field, which locate the filename of a file index. |
| Files | The files of a data, which select the regions of its functions that lie in one of them. |
| First Test Executable | The test executable of the first message of a compilation that names one, whose manifest names the package of the tests. |
| Function | A function of an export, with the filenames of the files it was made from and its export regions. |
| Functions | The functions of a data, whose regions are the regions of every function in their order. |
| Gate | The service of the application that holds the decoder, the reader, the parser, the input, the output and the errors, judges a report and names every gap of it. |
| Gates Coverage Adapter Java Script Object Notation | The crate gates_coverage_adapter_java_script_object_notation, the crate of the adapter of the coverage that fills the decoder over serde_json. |
| Index | The position of a value in a list, counted from zero, such as the index of the separator word or of an executable. |
| Infrastructure | The layer of the adapters Java Script Object Notation, File System and Syntax. |
| Java Script Object Notation | The adapter of the decoder over serde_json, which decodes an export out of its text. |
| Kind | The kind of an export region, code or annotation, which decides whether it is decoded. |
| Locate Filename | To locate the filename of a file index among the filenames of a function, and to refuse a file index past them. |
| Message | A message of Cargo in JSON on the output of a build. Also the error of a line of that output that is no such message. |
| Position Error Conversion | The conversion of the error of a position of an export region into the error of the adapter Java Script Object Notation, which names the path of the file of that region. |
| Reason | The reason of a message of Cargo, such as compiler-artifact. |
| Select Regions | To select the regions of the functions of a data that lie in one of its files. |
| Start Column | The column an export region starts at, as llvm-cov writes it. |
| Start Line | The line an export region starts on, as llvm-cov writes it, and the line of the start of a span, which a test boundary locates. |
| Syntax | The adapter of the parser over syn, which lexes the text of a source into its tokens with proc-macro2, parses those tokens into its file and visits every module of it with the test module visitor; the syntax tree of a source as syn parses it, which the test module visitor visits for the lifetime syntax; the error of the adapter for a text that is no Rust, which names the path of its source and the line and the column syn refuses it at and carries the error of syn, and the error of the gate that carries that error of the parser. |
| Test | A test of the package a measurement measures, which counts the regions it reaches while it runs. |
| Test Executable | An executable of a test that a message of Cargo names, with the manifest of its package. |
| Test Executable Absence | A message or a build that names no test executable. |
| Test Flag | The flag test of an artifact profile, which states whether Cargo compiled the artifact as a test. |
| Write Export Error | To write the error of a report that is no llvm-cov export, naming the cause. |
| Write File Error | To write the error of a region whose file index lies past the file indexes of its function. |
| Write Input Error | To write the error of an input that cannot be read, naming the cause. |
| Write Message Error | To write the error of a line of the output of a build that is no message of Cargo, naming the cause. |
| Write Position Error | To write the error of a position of a region that is no position, naming the path of its source. |
| Write Test Executable Absence | To write the error of a build that made no executable of a test. |
