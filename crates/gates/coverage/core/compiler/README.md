# gates_coverage_core_compiler

The compiler of a measurement: rustc, which names the directory of its library and so the tools of LLVM beside it.

It is a crate of the domain of the coverage, its concept in its `lib.rs`. It does no IO and keeps no state, and its tests are pure unit tests.
