# The ubiquitous language

| Word | What it means |
|---|---|
| First Argument | The first argument the program is given, which chooses its mode. |
| Gates Coverage Command Line | The crate gates_coverage_command_line, the program tool_coverage, which chooses between the gate and the measurement from its arguments. |
| Judgment | The mode that judges a report at a path, or on the standard input where no path is given. |
| Measurement Word | The word measure, which starts a measurement where it is the first argument. |
| Mode | What the program does with its arguments: the judgment of a report, or a measurement. |
| Respond Exit Code | To respond with the exit code of the outcome of the service the mode chooses. |
