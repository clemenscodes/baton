# stack_lock_adapter_device_tree_system_file_system

The adapter of the port DeviceTree of stack_lock_application over sysfs, the information of the NVIDIA driver, con2fbmap and nvidia-smi. Its tests run with
`cargo nextest run --profile debug -p stack_lock_adapter_device_tree_system_file_system`.
