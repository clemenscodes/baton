# The ubiquitous language

| Word | What it means |
|---|---|
| Compose Context Language | To join the language of Rust with the languages of every context that admits the path of a source. |
| Compose Dependency Language | To join the languages of the contexts the paths of a dependency list lie in with the foreign languages its foreign names name. |
| Compose Language | To join the languages of the contexts that admit a path or the languages of the foreign languages that foreign names name, and to compose the language of the keywords, of the standard library, of the words try and type of Rust or of the test words. |
| Context | A directory under a root with the language of its crate and the foreign names it admits, whose language joins the foreign languages it names. |
| Context Language | The language a source is judged against by its path: the language of Rust and the languages of the contexts that admit the path. |
| Current Directory | The component . of a path, which names the directory the path starts in and which the directory of a context leaves out. |
| Foreign Language | The names a crate uses from a crate outside it, named by the foreign name of that crate. |
| Gates Vocabulary Language Core Languages | The crate gates_vocabulary_language_core_languages, every language of a repository: Rust, the contexts and the foreign languages. |
| Keyword | A word Rust reserves or a primitive type of Rust, which every source admits as the whole identifier it is and never as a word of a longer one. |
| Rust | The language of Rust itself: its keywords and the names of its standard library, which every source admits where its code uses them, and the words try and type, which every identifier may hold. |
| Select Context | To select the context whose directory is exactly a path, without the current directory in front of it, or to refuse a path that is the directory of no context. |
| Standard Library | The standard library of Rust, whose names every source admits. |
| Test Word | A word docs/STYLE.md prescribes for tests, tests, fixture, helper, factory or expectation, which the test code of every source may hold alone and in a compound. |
