# The ubiquitous language

| Word | What it means |
|---|---|
| Absence | The state of a directory that is not there, of a manifest a directory does not hold and of an attribute that is anything else than cfg(test). |
| Book | The page of a context that lists its terms with their definitions, a table with no row for a context of no term. |
| Create File | To create the temporary file of a path for a text, as the writer does. |
| Detect Directory | To detect whether a directory is present or absent, for the writer and for the book of a press. |
| Directory Presence | Whether a directory is present or absent. |
| Documents | The directory docs of a crate, where its book is written. |
| File Name | The name of the file a book is written to. |
| Gates Vocabulary Language Core Books | The crate gates_vocabulary_language_core_books, the books of the contexts, with the port of the writer they go out through. |
| Heading | The first line of a book. |
| Presence | The state of a directory that is there, of a manifest a directory holds and of an attribute that is exactly cfg(test). |
| Replace File | To put the temporary file of a path in the place of its file, and to remove the temporary file where that fails. |
| Row | One line of the table of a book, a term and its definition. |
| Separator Escape | The backslash and the bar that a row shows in place of a bar inside a definition, so the bar separates no columns. |
| Table Head | The line of a book that names its two columns. |
| Table Rule | The line of a book under its table head. |
| Writer | The port that creates the temporary file of a path, replaces the file with it and detects a directory. |
