# The ubiquitous language

| Word | What it means |
|---|---|
| Argument | An argument of an invocation, after its program, and an argument the program is given on its command line. |
| Command | A command a measurement starts, as its words: the command that compiles the tests or the command that runs them. |
| Compiler | The compiler of Rust, rustc, which names the directory of its library, beside which the profile tools lie. |
| Compose Command | To compose the command of the operating system that starts an invocation. |
| Compose Completion | To compose the completion of a program from its status and the output it captured. |
| Coverage | The crate that judges whether the tests of a crate reach every region of its sources outside their test modules, and the context of that crate. |
| Gate | The service of the application that holds the decoder, the reader, the parser, the input, the output and the errors, judges a report and names every gap of it. |
| Gates Coverage Adapter Process | The crate gates_coverage_adapter_process, the crate of the adapter of the coverage that fills the spawner over the processes of the operating system. |
| Infrastructure | The layer of the adapters Java Script Object Notation, File System and Syntax. |
| Process | The adapter of the spawner over the processes of the operating system. |
