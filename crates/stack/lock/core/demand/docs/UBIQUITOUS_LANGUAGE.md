# The ubiquitous language

| Word | What it means |
|---|---|
| Graphics Demand | The demand of an eligible application for the GPU of a lock, with the process that waits for it, served in the order it was made. |
| Stack Lock Core Demand | The crate stack_lock_core_demand, the demand of an eligible application for a GPU, with the process that waits for it. |
| Waiter Identifier | The identifier of the process that waits for a demand, which leaves the queue once that process ends. |
