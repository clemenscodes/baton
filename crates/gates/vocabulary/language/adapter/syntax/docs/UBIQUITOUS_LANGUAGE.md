# The ubiquitous language

| Word | What it means |
|---|---|
| Absence | The state of a directory that is not there, of a manifest a directory does not hold and of an attribute that is anything else than cfg(test). |
| Attribute Content | What an attribute holds behind its hash mark, its path and its tokens or its value. |
| Attribute Visitor | The visitor of the syntax of a source that composes a defect of every test attribute in front of its production end and of every comment, and keeps the start of every comment. |
| Code Occurrences | The occurrences of one part of a source while the syntax composes it, every identifier token sorted into the identifiers or the declarations of its code by the starts of the declarations. |
| Column Offset | A column of a line of a source counted from zero, as proc_macro2 counts it. |
| Compose Source | To compose a source from the identifier tokens of its text, those in front of its production end into its production code and the others into its test code, apart from the tokens of its comments and of the names of its test functions, and from its defects. |
| Condition | The predicate of a configuration or of the attribute cfg_attr, under which Rust compiles what it stands on. |
| Configuration | The attribute cfg of Rust, which compiles what it stands on only under its condition. |
| Constant Constructor | The function new of a type that is a constant, the one constructor beside the conversions, whose name docs/STYLE.md declares. |
| Constant Marker | The keyword const in front of a function, which makes it callable at compile time. |
| Count Test Conditions | To count how often the condition of an attribute cfg or cfg_attr names test, which makes that attribute a test attribute. |
| Declaration Visitor | The visitor of the syntax of a source that inserts the start of every identifier the source declares and of the name of every test function. |
| Error Kind | The kind of an io::Error, such as the invalid data of a manifest that is no TOML. |
| Gate | The service that reads and parses the sources of a run and refuses a source where its text is no Rust, where its production code or its test code names or declares an unknown identifier or where it has a defect, and that refuses a context where its terms hold an unused term. |
| Gates Vocabulary Language Adapter Syntax | The crate gates_vocabulary_language_adapter_syntax, the adapter of the parser over syn. |
| Group | A token tree of the tokens between a pair of delimiters. |
| Hash Mark | The mark # an attribute opens with. |
| Identifier Token | An identifier of a token stream, or the suffix of a literal, with the start of its token. |
| Implementation Item | An item of an impl block: a function, a constant or a type, whose name the trait it implements declares where it implements one. |
| Infrastructure | The layer of the library whose adapters, the file system, the decoder over TOML and the parser over syn, fill its ports. |
| Insert Binding | To insert the identifier that a let, a parameter, a closure or a loop binds as its whole pattern, whatever its case, as a declaration. |
| Insert Comment | To insert the comment defect of a comment attribute at its start position and to keep that start position among the comment starts. |
| Insert Comment Defect | To insert the defect and the start of an attribute that is a comment. |
| Insert Declaration | To insert the start of a declared identifier into a declaration visitor. |
| Insert Implementation Item | To insert the name of an implementation item. |
| Insert Punctuation Token | To insert a punctuation token into the production tokens. |
| Insert Signature | To insert the name of a function, which its signature holds, unless it is the constant constructor. |
| Insert Test Attribute | To insert the defect of a test attribute that stands in front of the end of the production code. |
| Insert Test Function | To insert the start of the name of a test function into a declaration visitor. |
| Insert Token | To insert the occurrence of an identifier token into the code occurrences, as a declaration where a declaration starts at it and as an identifier everywhere else, and to refuse a token that is no occurrence. |
| Insert Trait Item | To insert the name of a trait item. |
| Measure Production End | To measure the production end of a source from its last item, which is its test module where it is a module tests with the attribute cfg(test). |
| Mutability Marker | The keyword mut in front of the identifier of a pattern, which makes the identifier a binding. |
| Node | A part of the syntax of a source that a visitor visits. |
| Pattern | A pattern of Rust that binds or matches a value, such as the pattern of a let, a parameter, a closure or a loop. |
| Presence | The state of a directory that is there, of a manifest a directory holds and of an attribute that is exactly cfg(test). |
| Production End | The start of the attribute cfg(test) of the test module of a source, or the text end where a source has no test module, which separates its production code from its test code. |
| Program Start | The function main a program of Rust starts with, whose name Rust declares. |
| Punctuation Token | A sign of the code with the position it starts at, which turns into the punctuation among the production tokens. |
| Reference Marker | The keyword ref in front of the identifier of a pattern, which makes the identifier a binding. |
| Signature | The name, the generic parameters, the parameters and the return type of a function. |
| Source Occurrences | The identifiers of a source, sorted into its production code and its tests, and the defects of its tokens. |
| Span | The location of a token in the text of a source, which its start states. |
| Subpattern | The pattern behind the at sign of a binding, which makes the identifier in front of it a binding. |
| Suffix | The end that follows the part of a text: the suffix separator and the process identifier that a temporary path carries behind the path of its file, and the name behind the digits or the quotes of a literal. |
| Syntax | The structure of the text of a source as Rust defines it, which a text that is no Rust lacks, and the adapter of the parser over the crate syn, which parses that structure. |
| Syntax Literal | A literal of a token stream as syn reads it, together with its suffix. |
| Test Attribute Presence | The start of an attribute that is exactly cfg(test), or the absence of it in every other attribute. |
| Test Function | A function that carries the attribute test or, in the browser, wasm_bindgen_test, whose name is the sentence of its test and is not judged. |
| Test Module | The module tests at the bottom of a source that holds its tests, whose code is the test code of the source. |
| Token Stream | The tokens of a text or of a group, one after another. |
| Token Tree | One token of a token stream. |
| Trait Item | An item of a trait: a function, a constant or a type. |
| Typed Pattern | The pattern inside a pattern with a type, such as the pattern of a parameter. |
