# The ubiquitous language

| Word | What it means |
|---|---|
| Command Line | The arguments the process is started with: the paths of the sources to judge, the paths of the sources whose terms to judge, or the directories whose books to publish. |
| Compose Gate | To compose the gate of a session over the vocabulary, the file system, the decoder of manifests and the parser of sources, or the errors that the vocabulary cannot form its languages with. |
| Edition | The report of the edition of a press: every book entry that went out or was passed over on the report, and every error on the errors. |
| Error Stream | The stream every error of a session is reported on. |
| Examine Session | To examine the paths of a session that publishes no book: to report their production tokens, or to judge them. |
| Exit Code | The status the process exits with. |
| Flush Stream | To flush the report and the errors of an edition, so every line written to them goes out. |
| Gates Vocabulary Language Adapter Command Line | The crate gates_vocabulary_language_adapter_command_line, the command line of the vocabulary gate and the session that serves it. |
| Judge Session | To judge the sources of a session, or the terms where it asks for them. |
| Outcome | Whether the command line succeeded or failed, which the process exits with. |
| Path Resolution | The resolution of the path judgment of a session by its gate. |
| Presentation | The layer of the library a person or a program reaches: its command line. |
| Publish Book | To dispatch the book edition of the directories the command line names to a press over the file system and to report its edition. |
| Report | The stream every book that goes out, and every book whose directory is nowhere, is reported on. |
| Report Book Entries | To report every book entry of an edition of the press and to combine their outcomes into one. |
| Report Book Entry | To write a book entry to the report where its book went out or was passed over, and to the errors where an error refused it. |
| Report Edition | To write every book entry of an edition to the report or to the errors, or the error that refused the edition, flush both and respond with the outcome. |
| Report Judgment | To write every error of the judgment of a gate to the errors, flush them and respond with the outcome of the judgment. |
| Report Production Tokens | To write the production tokens of the sources to the report, one token on a line, so a gate reads the names and the signs of the code and no text of it. |
| Respond Exit Code | To judge the paths or their terms or to publish the books the command line names, through a session, and to respond with the exit code. |
| Session | The vocabulary a command line is served with, and the report and the errors it writes to; it composes the adapters of the gate and the press and runs their use cases. |
| Success | The outcome of a command line whose every judgment and every book succeeded. |
| Term Resolution | The resolution of the term judgment of a session by its gate. |
| Token Resolution | The resolution of the token selection of a session by its gate. |
