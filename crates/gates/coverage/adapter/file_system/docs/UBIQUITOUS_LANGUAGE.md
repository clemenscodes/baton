# The ubiquitous language

| Word | What it means |
|---|---|
| Coverage | The crate that judges whether the tests of a crate reach every region of its sources outside their test modules, and the context of that crate. |
| Directory Entry | An entry of a directory as the file system lists it, such as a profile in a profile directory. |
| File System | The adapter of the reader over the file system of the host. |
| Gate | The service of the application that holds the decoder, the reader, the parser, the input, the output and the errors, judges a report and names every gap of it. |
| Gates Coverage Adapter File System | The crate gates_coverage_adapter_file_system, the crate of the adapter of the file system of the coverage, which fills the reader and the profile store. |
| Infrastructure | The layer of the adapters Java Script Object Notation, File System and Syntax. |
| Kind | The kind of an export region, code or annotation, which decides whether it is decoded. |
| Paths | The path of every source a report keeps a span of, each path once and in order. |
| Process | The adapter of the spawner over the processes of the operating system. |
| Profile Extension | The extension profraw of a profile. |
| Report Directory | The directory of the report of a measurement, which the measurement creates where it is missing. |
| Report Path | The path of the report of a measurement. |
| Select Profiles | To select the path of every profile among the directory entries of a profile directory, in their order. |
