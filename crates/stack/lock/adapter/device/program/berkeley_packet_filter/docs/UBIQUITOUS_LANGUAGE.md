# The ubiquitous language

| Word | What it means |
|---|---|
| Absence Code | The error number two of the kernel for an object or a key that is absent. |
| Add Immediate | The operation that adds an immediate to a register. |
| Address | The address of a buffer as a word of the attribute. |
| Allowance | The verdict that allows an access, one. |
| Allowance Position | The position of the instruction of the allowance. |
| Ancestor Helper | The helper of the kernel that answers the identifier of the ancestor of the task at a level, helper 123. |
| Ancestry Depth | The number of levels of cgroups the device program checks for a permission, 16 by default. |
| And Immediate | The operation that masks a register with an immediate. |
| Attribute | The attribute of a system call bpf, a buffer the kernel reads the arguments of the call from. |
| Block Type | The kind one of a block device in the key of a device. |
| Bytes | The bytes of an instruction, of the device program or of an attribute. |
| Call | The error of a system call bpf that failed. |
| Call Helper | The operation that calls a helper of the kernel. |
| Cgroup | The identifier of a control group of the unified hierarchy a permission admits. |
| Character Type | The kind two of a character device in the key of a device. |
| Code | The bytes of the device program. |
| Compose | To make an instruction of its operation, its registers, its offset and its operand. |
| Compose Bytes | To compose the bytes of an instruction or of the device program. |
| Compose Device Key | To compose the key of a device file, its kind, its major and its minor. |
| Compose Permission Key | To compose the key of a permission, the identifier of a cgroup and the lock. |
| Configuration | The program configuration of the adapter. |
| Context | The register that holds the context of the device program. |
| Context Register | The register that holds the context of the device program, the access the kernel asks about. |
| Denial | The verdict that denies an access, zero. |
| Descriptor | The descriptor of a map, of the program or of a cgroup. |
| Destination | The destination register of an instruction. |
| Device Descriptor | The descriptor of the map of the devices. |
| Device Filter | The program of the type of a device filter of a cgroup, assembled by hand, that reads the map of the devices and the map of the permissions and answers whether a cgroup may open a device. |
| Device Kernel | The seam of the kernel over the eight operations of bpf the adapter needs, so the adapter is proven without root. |
| Device Kernel Type | The type of the device kernel a device program holds. |
| Device Key | The key of a device file in the map of the devices. |
| Device Key Offset | The offset of the key of a device on the stack. |
| Device Key Size | The size of the key of the map of the devices, twelve. |
| Device Limit | The highest number of device files of the map of the devices. |
| Device Map | The map of the devices, opened at its pin for an insertion or a deletion. |
| Device Pin | The name of the pin of the map of the devices, devices. |
| Device Program Port | The port DeviceProgram as the adapter imports it. |
| Distance | The offset of a jump from its position to the allowance. |
| Entry Limit | The highest number of entries of a map. |
| Equality Jump | The operation that jumps when a register equals an immediate. |
| Exit | The operation that ends the device program with the verdict in the first register. |
| Filter | The module of the device filter, the device program as its instructions. |
| Hierarchy | The error of the root of the unified hierarchy that could not be opened. |
| Hierarchy Directory | The root of the unified cgroup hierarchy the device program is attached to, /sys/fs/cgroup unless an option names another. |
| Hierarchy File | The open directory of the root of the unified hierarchy. |
| Inequality Jump | The operation that jumps when a register differs from an immediate. |
| Instruction | One instruction of the device program, eight bytes of an operation, two registers, an offset and an operand. |
| Instructions | The instructions of the device filter. |
| Jump Position | The position of a jump to the allowance. |
| Jump To Allowance | To make a jump from a position to the instruction of the allowance. |
| Jumps | The positions of the jumps to the allowance, filled once the allowance is placed. |
| Kernel | The module of the device kernel, the seam of the calls of the kernel. |
| Key | The bytes of a key of a map. |
| Key Size | The size of the key of a map. |
| Level | The level of an ancestor of the task the device program checks. |
| Level Operand | The level of an ancestor as an operand. |
| License | The license the device program is loaded under. |
| Load Double Word | The operation that loads a double word immediate, in two instructions, which carries the descriptor of a map. |
| Load Map | The two instructions that load the descriptor of a map into a register. |
| Load Word | The operation that loads a word from the memory of a register. |
| Lock Offset | The offset of the lock of a device on the stack. |
| Lock Size | The size of the value of the map of the devices, the lock, four. |
| Lock Value | The lock a device file belongs to, the value in the map of the devices. |
| Map | The attribute of a creation of a map. |
| Map Lookup Helper | The helper of the kernel that looks a key up in a map, helper 1. |
| Map Source | The source that marks a load of a double word as the descriptor of a map. |
| Move Immediate | The operation that moves an immediate into a register. |
| Move Register | The operation that moves a register into another. |
| Object | A pinned map or program the adapter fastens or opens at a path of bpffs. |
| Offset | The offset of an instruction, from the base of a register or to a jump. |
| Offset Bytes | The two bytes of the offset of an instruction. |
| Operand | The immediate operand of an instruction. |
| Operand Bytes | The four bytes of the operand of an instruction. |
| Operation | The operation byte of an instruction. |
| Operation Text | The name of the operation of a system call bpf in an error. |
| Padding Offset | The offset of the padding of the key of a permission on the stack. |
| Path | The path of a pin or of the root in an error. |
| Permission Descriptor | The descriptor of the map of the permissions. |
| Permission Key | The key of a cgroup and a lock in the map of the permissions. |
| Permission Key Offset | The offset of the key of a permission on the stack. |
| Permission Key Size | The size of the key of the map of the permissions, sixteen. |
| Permission Limit | The highest number of cgroups of the map of the permissions. |
| Permission Map | The map of the permissions, opened at its pin for a permission or a revocation. |
| Permission Pin | The name of the pin of the map of the permissions, permissions. |
| Pin | The attribute of a pin of an object. |
| Pin Directory | The directory of bpffs the maps and the program are pinned under, /sys/fs/bpf/baton unless an option names another. |
| Pin Path | The path of a pin of bpffs. |
| Position | The position of an instruction in the device program. |
| Presence Size | The size of the value of the map of the permissions, one. |
| Presence Value | The value of a permitted cgroup in the map of the permissions, one. |
| Program Configuration | The root of the unified hierarchy, the directory of the pins and the depth of the ancestry. |
| Program Pin | The name of the pin of the device program, program. |
| Register | The byte of an instruction that holds its source and its destination. |
| Source | The source register of an instruction. |
| Stack | The register that holds the stack of the device program. |
| Stack Lock Adapter Device Program Berkeley Packet Filter | The crate stack_lock_adapter_device_program_berkeley_packet_filter, the adapter of the port DeviceProgram of stack_lock_application over the system call bpf and the unified cgroup hierarchy, with no library of bpf. |
| Stack Register | The register that holds the stack of the device program. |
| Store Double Word | The operation that stores a double word into the stack. |
| Store Word | The operation that stores a word into the stack. |
| Store Word Immediate | The operation that stores an immediate word into the stack. |
| System Kernel | The device kernel over the crate berkeley_packet_filter, the real system calls of bpf. |
| Try Attach Device Program | To attach the device program to the root of the unified hierarchy through the device kernel. |
| Try Check Program | To tell whether the device program is already pinned, so it is installed once. |
| Try Create Hash Map | To create a hash map through the device kernel. |
| Try Create Map | To create a map through the system call bpf. |
| Try Delete | To delete a key of a map and take a key that is already absent as no error. |
| Try Delete Element | To delete an element of a map through the device kernel. |
| Try Delete Key | To delete a key of a map and take a key that is already absent as no error. |
| Try Detach Device Program | To detach the device program from the root of the unified hierarchy through the device kernel. |
| Try Fasten Object | To fasten a map or the program at a path of bpffs, so a later run finds it again. |
| Try Load Device Program | To compose the device filter and load it as the device program through the device kernel. |
| Try Load Program | To compose the device filter and load it through the system call bpf. |
| Try Open Hierarchy | To open the root of the unified hierarchy as a directory the device program is attached to. |
| Try Open Object | To open a pinned map or program at a path of bpffs. |
| Try Update Element | To update an element of a map through the device kernel. |
| Type Mask | The mask that keeps the kind of a device out of the access type. |
| Value | The bytes of a value of a map. |
| Value Size | The size of the value of a map. |
| Word | The descriptor of an object as a word of the attribute. |
