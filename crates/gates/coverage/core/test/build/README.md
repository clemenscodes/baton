# gates_coverage_core_test_build

The test build of a package: the executables of its tests and the manifest of their package, which the compilation of a measurement states.

It is a crate of the domain of the coverage, its concept in its `lib.rs`. It does no IO and keeps no state, and its tests are pure unit tests.
