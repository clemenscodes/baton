# module

The check `module`. It evaluates a NixOS system with `nixosModules.default` and one lock, and refuses
the module where its rule of udev does not enclose the GPU at the bind of its driver, does not refresh
the slot when a node appears, where the enclosure does not admit every application and the default
owner, where sudo allows more than `acquire`, `release` and `status` of `baton_host`, where the
activation does not admit the applications, or where `baton` is not wrapped with the path of
`baton_host`.
