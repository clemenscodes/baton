# The ubiquitous language

| Word | What it means |
|---|---|
| Compose Error | To turn an error of the file system into an error of a cgroup. |
| Compose Group Path | To compose the directory of a cgroup below the root of the unified hierarchy. |
| Configuration | The group configuration of the adapter. |
| Control Group | The adapter of the port ControlGroup, which creates, reads, fills and removes the cgroups of the eligible applications below the root of the unified hierarchy. |
| Control Group Port | The port ControlGroup as the adapter imports it. |
| Events Name | The name cgroup.events of the file that tells whether a cgroup holds a process. |
| Events Path | The file cgroup.events of a cgroup, which tells whether it holds a process. |
| Events Text | The text of the file cgroup.events of a cgroup. |
| Group | The error of a cgroup that could not be created, read, filled or removed. |
| Group Configuration | The root of the unified cgroup hierarchy. |
| Hierarchy Directory | The root of the unified cgroup hierarchy, /sys/fs/cgroup unless an option names another. |
| Line | A line of the file cgroup.events. |
| Metadata | The metadata of the directory of a cgroup, whose inode is the identifier of the cgroup. |
| Path | The path of a file of a cgroup in an error. |
| Population Line | The line populated 1 of a cgroup that holds a process. |
| Processes Name | The name cgroup.procs of the file a process is moved into. |
| Processes Path | The file cgroup.procs of a cgroup, which a process is moved into by writing its identifier. |
| Relative Text | The path of a cgroup without its leading slash. |
| Stack Lock Adapter Control Group Unified Hierarchy | The crate stack_lock_adapter_control_group_unified_hierarchy, the adapter of the port ControlGroup of stack_lock_application over the files of the unified cgroup hierarchy. |
