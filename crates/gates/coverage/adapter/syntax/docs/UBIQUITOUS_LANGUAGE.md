# The ubiquitous language

| Word | What it means |
|---|---|
| Absence | The lack of what a measurement needs, named by what is lacking. |
| Attribute | An attribute of a module as syn parses it, and the test attribute, the attribute cfg test, which opens the test module it stands on where its path is the configuration name and its tokens are the test name. |
| Brace | The braces around the items of an inline module, the end of which lies on the closing line of a test module. |
| Column Offset | The column a syntax error starts at as proc-macro2 counts it, from 0, so that the column of that syntax error lies 1 above it. |
| Compose Test Boundaries | To compose the test boundary of every test attribute that stands on a test module. |
| Compose Test Boundary | To compose the test boundary of a test module from the path of its source, the opening line of its test attribute and its closing line. |
| Configuration Name | The name cfg, the path of the test attribute. |
| Coverage | The crate that judges whether the tests of a crate reach every region of its sources outside their test modules, and the context of that crate. |
| File | A file of an export, named by its filename, whose regions the data keeps, and the error of a code region whose file index its function lacks, which names that file index and the file count of that function; and the file of syn, the items of a source as syn parses them, whose modules the test module visitor visits. |
| Gate | The service of the application that holds the decoder, the reader, the parser, the input, the output and the errors, judges a report and names every gap of it. |
| Gates Coverage Adapter Syntax | The crate gates_coverage_adapter_syntax, the crate of the adapter of the coverage that fills the parser over syn and proc-macro2. |
| Hash Mark | The mark # an attribute starts with, the line of which is the opening line of the test module the test attribute stands on. |
| Identifier | The name of a module as syn parses it, the test module name for a test module. |
| Infrastructure | The layer of the adapters Java Script Object Notation, File System and Syntax. |
| Name | The name of a variable of the environment, of a profile directory or of a tool. |
| Presence | The mapping presence of executables of which at least one carries a mapping section. |
| Push Test Boundaries | To push a test boundary for every test attribute of a module. |
| Stream | Whether a measurement captures the output of an invocation or the invocation writes it where the measurement writes its own. |
| Syntax | The adapter of the parser over syn, which lexes the text of a source into its tokens with proc-macro2, parses those tokens into its file and visits every module of it with the test module visitor; the syntax tree of a source as syn parses it, which the test module visitor visits for the lifetime syntax; the error of the adapter for a text that is no Rust, which names the path of its source and the line and the column syn refuses it at and carries the error of syn, and the error of the gate that carries that error of the parser. |
| Test Attribute Presence | What an attribute of a test module is to the test module visitor: a presence that names the opening line where it is the test attribute, and an absence where it is any other attribute. |
| Test Module Name | The name tests, which the module of a test module bears. |
| Test Module Visitor | The visitor of syn that visits every module of the file of a source, nested modules included, and lists the test boundary of every test module among them, or the error of that test boundary, from the line of the hash mark of its test attribute to the line of the end of its brace. |
| Test Name | The name test, the tokens of the test attribute inside its parentheses. |
| Token | A token of the text of a source as proc-macro2 lexes it: the tokens of a source, which syn parses into its file, and the tokens of an attribute inside its parentheses, the test name for the test attribute. |
