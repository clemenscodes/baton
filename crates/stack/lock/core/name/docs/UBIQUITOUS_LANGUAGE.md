# The ubiquitous language

| Word | What it means |
|---|---|
| Application Name | The name of an eligible application of a lock, such as render or guest, of letters, digits, _ and -, never beginning with -, which names its cgroup. |
| Character | One character of the text of a name. |
| Character Presence | Whether every character of a text may stand in a name. |
| Check Character | To tell whether a character may stand in a name. |
| Lock Name | The name of a lock of a GPU, such as rtx3080, of letters, digits, _ and -, never beginning with -, which names its records and its tree of cgroups. |
| Option Absence | Whether a text does not begin with -, so no program reads it as an option. |
| Stack Lock Core Name | The crate stack_lock_core_name, the name of a lock and the name of an eligible application of the mutex around a GPU. |
| Text | The text of a name. |
