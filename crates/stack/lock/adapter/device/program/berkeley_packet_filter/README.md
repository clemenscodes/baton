# stack_lock_adapter_device_program_berkeley_packet_filter

The adapter of the port DeviceProgram of stack_lock_application over the system call bpf and the unified cgroup hierarchy, with no library of bpf. Its tests run with
`cargo nextest run --profile debug -p stack_lock_adapter_device_program_berkeley_packet_filter`.
