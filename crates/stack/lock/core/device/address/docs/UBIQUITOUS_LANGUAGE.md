# The ubiquitous language

| Word | What it means |
|---|---|
| Address Text | The error of a text that is no device address. |
| Bus | The PCI bus of a device address. |
| Bus Text | The text of the bus of a device address. |
| Device Address | The PCI address of a function of a device, such as 0000:03:00.0, its domain, its bus, its slot and its function. |
| Domain | The PCI domain of a device address, the first four hexadecimal digits. |
| Domain Text | The text of the domain of a device address. |
| Function | The function of a device address, from 0 to 7, such as the graphics and the audio of one card. |
| Function Limit | The highest function of a PCI slot, 7. |
| Function Text | The text of the function of a device address. |
| Hexadecimal Radix | The radix 16 the parts of a device address are written in. |
| Maybe Parts | The domain, the bus, the slot and the function of a text, where it is a device address. |
| Remainder Text | What of a text of a device address is left to read. |
| Share Slot | To tell whether two device addresses are functions of the same card. |
| Slot | The slot of a device address, which every function of one card shares. |
| Slot Limit | The highest slot of a PCI bus, 31. |
| Slot Text | The text of the domain, the bus and the slot of a device address, such as 0000:03:00. |
| Stack Lock Core Device Address | The crate stack_lock_core_device_address, the PCI address of a GPU, its domain, its bus, its slot and its function. |
| Text | The text of a device address. |
| Width Presence | Whether every part of a text of a device address has its width. |
