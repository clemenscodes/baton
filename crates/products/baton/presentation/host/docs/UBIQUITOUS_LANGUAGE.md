# The ubiquitous language

| Word | What it means |
|---|---|
| Application | The application a request of baton_host names. |
| Force | The flag of an acquisition that ends the users of a GPU instead of waiting for them. |
| Host Adapters | The adapters of every port of the administration, which baton_host composes. |
| Passthrough | The flag of an acquisition that hands the GPU to vfio-pci for a guest. |
| Process | The process of an acquisition, which moves into the cgroup of its application. |
| Products Baton Presentation Host | The crate products_baton_presentation_host, the helper baton_host run as root, which administers the locks of the GPUs and answers the requests of baton. |
| Request | A request of baton_host, such as enclose or acquire, with its arguments. |
| Try Respond Exit Code | To respond to a request of baton_host and answer its exit code. |
| Users | The request of baton_host that names every user of the GPU of a lock. |
| Yield Presence | The flag --yielding of an admission, which makes the default owner yield to every acquisition. |
