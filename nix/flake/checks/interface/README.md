# interface

The check `interface`. Over what `tool_vocabulary --tokens` prints for the production code it refuses a
glob import, a `pub use` of any visibility that reaches past the own child of its module, a `pub use` of any
visibility whose first segment is no child module the same file declares with `mod`, such as another crate,
`crate::` or `super::`, because no crate passes on an item of another crate and an application publishes
types of its own that translate the values of its core, and, outside `lib.rs`, a `pub use` of a name
the child module already published, as "Layers publish, modules do not" in `docs/STYLE.md` states.
`use super::*;` of a test module is never read.
