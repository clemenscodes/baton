# stack_lock_adapter_task_table_process_file_system

The adapter of the port TaskTable of stack_lock_application over the descriptors, the commands and the cgroups under /proc and the signals of rustix. Its tests run with
`cargo nextest run --profile debug -p stack_lock_adapter_task_table_process_file_system`.
