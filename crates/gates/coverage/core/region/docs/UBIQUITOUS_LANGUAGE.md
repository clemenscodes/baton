# The ubiquitous language

| Word | What it means |
|---|---|
| Execution Count | How often the tests ran a region. |
| Gates Coverage Core Region | The crate gates_coverage_core_region, the crate of the domain of the coverage that holds the region, a span with the count of its executions. |
| Region | A span of a source with its execution count, as llvm-cov exports it for one copy of a function. |
