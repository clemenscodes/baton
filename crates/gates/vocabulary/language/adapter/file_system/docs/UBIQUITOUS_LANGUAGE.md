# The ubiquitous language

| Word | What it means |
|---|---|
| Compose Temporary Path | To compose the temporary path beside the path of a file. |
| Error Kind | The kind of an io::Error, such as the invalid data of a manifest that is no TOML. |
| File System | The adapter of the reader and the writer over the files of the machine. |
| Gate | The service that reads and parses the sources of a run and refuses a source where its text is no Rust, where its production code or its test code names or declares an unknown identifier or where it has a defect, and that refuses a context where its terms hold an unused term. |
| Gates Vocabulary Language Adapter File System | The crate gates_vocabulary_language_adapter_file_system, the adapter of the reader and the writer over the files of the machine. |
| Infrastructure | The layer of the library whose adapters, the file system, the decoder over TOML and the parser over syn, fill its ports. |
| Metadata | What the file system states about a path, such as whether it is a directory. |
| Pending Directory | A directory under the directory a walk starts at whose entries are still to be listed. |
| Process Identifier | The identifier the operating system gives the running process, which a temporary path carries in its suffix. |
| Removal | The removal of a temporary file whose replacement failed, and the error where that removal failed as well. |
| Replacement | The renaming of the temporary file of a path over that file. |
| Source Extension | The extension rs that the name of a Rust file ends with. |
| Suffix | The end that follows the part of a text: the suffix separator and the process identifier that a temporary path carries behind the path of its file, and the name behind the digits or the quotes of a literal. |
| Temporary Path | The path of a file with a suffix, beside the file, which a text is first put into and then renamed over the file. |
| Walk Directory | To walk a directory and every directory under it and list every Rust file in them, in their order. |
