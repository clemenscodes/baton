# The ubiquitous language

| Word | What it means |
|---|---|
| Compose Source Directory | To compose the source directory beside the manifest of a test build. |
| Domain | The layer of the report, its regions, spans, positions and gaps, the sources, their test boundaries and the sections these decide, and the ports the gate reaches the world through, the decoder, the reader and the parser. |
| Executable | A program the build of the tests made. |
| Gates Coverage Core Test Build | The crate gates_coverage_core_test_build, the crate of the domain of the coverage that holds the test build, the executables of the tests and the manifest of their package. |
| Manifest Path | The path of the manifest of the package whose tests a build made. |
| Name | The name of a variable of the environment, of a profile directory or of a tool. |
| Package Directory | The directory of the package whose manifest a test build names, with the source directory under it. |
| Path | The path of a file or a directory: of a source or of a file of an export, as llvm-cov names it, of the source a test boundary lies in, of a report, a profile, a profile directory, a tool, a manifest or an executable; and the path of an attribute as syn parses it, cfg for the test attribute. |
| Source Directory | The directory src beside the manifest, whose sources a measurement reports. |
| Source Directory Name | The name src of the source directory. |
| Test Build | The executables the build of the tests made, with the manifest of their package. |
